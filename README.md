# Mamba Code Analyzer

A local GPU-powered Gradio application for analyzing Mamba code
using a fine-tuned Mamba/Mistral language model.

## Important

The application runs locally on the user's computer.

Inference is performed using the user's own GPU when CUDA is
available.

The project does not require a central GPU server.

## Requirements

- Python 3.11
- NVIDIA GPU recommended
- NVIDIA driver with CUDA support
- Sufficient GPU VRAM
- Internet connection for downloading the model
